# 🎯 나만의 CS 퀴즈 게임 (Console Quiz Game)

## 📌 1. 프로젝트 개요

Python 콘솔 기반의 인터랙티브 퀴즈 게임 프로그램입니다.  
클래스 기반 객체지향 설계(OOP)로 작성되었으며, JSON 파일 입출력을 통해 프로그램 재시작 후에도 퀴즈 목록과 최고 점수가 유지되는 **데이터 영속성**을 제공합니다. 또한, 입력 예외 처리 및 데이터 손상 자동 복구 기능을 갖추고 있습니다.

---

## 💡 2. 퀴즈 주제 및 선정 이유

- **주제**: CS (Computer Science) 기초 지식 (자료구조, 네트워크, DB, OS, 알고리즘 등)
- **선정 이유**: 개발자 입문 과정에서 컴퓨터 과학 핵심 기본기를 점검하고 복습하는 것이 무엇보다 중요하기 때문입니다.

## 🚀 3. 실행 방법

`git clone`으로 저장소를 전달받은 사용자는 아래 절차에 따라 디렉터리로 이동 후 프로그램을 실행합니다.

### 1) 저장소 복제 및 디렉터리 이동

```bash
git clone <저장소-URL>
cd codyssey/E1/2   # 해당 프로젝트 디렉터리로 이동
```

### 2) 프로그램 실행

```bash
# 디렉터리(E1/2) 내에서 실행 시
python main.py

# 또는 프로젝트 최상위(루트) 디렉터리에서 실행 시
python E1/2/main.py
```

## ⚙️ 4. 기능 목록

1. **퀴즈 풀기 (1번)**
   - 저장된 CS 퀴즈 문제를 차례대로 출제합니다.
   - 각 문제마다 1~4번 중 정답을 선택받아 즉시 정/오답을 판정합니다.
   - 모든 문제를 푼 후 점수(100점 만점 기준)를 계산하며, 기존 최고 점수를 초과한 경우 최고 점수를 갱신하고 자동 저장합니다.
2. **퀴즈 추가 (2번)**
   - 사용자가 새로운 퀴즈 문제, 선택지 4개, 정답 번호를 직접 입력하여 추가할 수 있습니다.
   - 추가된 퀴즈는 `state.json`에 즉시 저장됩니다.
3. **퀴즈 목록 (3번)**
   - 현재 등록되어 있는 모든 퀴즈의 질문 목록을 확인할 수 있습니다.
4. **점수 확인 (4번)**
   - 기록된 최고 점수와 당시의 정답률(맞힌 문제 수 / 전체 문제 수)을 확인합니다.
5. **예외 처리 & 안전한 종료 (5번 및 입력 예외)**
   - 잘못된 숫맥 범위(1~5 외) 입력이나 문자열 입력 시 안내 메시지 후 재입력 흐름을 유지합니다.
   - `Ctrl+C` (`KeyboardInterrupt`) 또는 `EOF` 발생 시 진행 상황을 안전하게 저장하고 비정상 종료 없이 안내 메시지와 함께 종료합니다.
   - `state.json` 데이터가 없거나 손상된 경우 기본 CS 퀴즈 데이터로 자동으로 복구/초기화합니다.

## 💾 6. 데이터 파일 설명 (`state.json`)

- **파일 경로**: `E1/2/state.json` (프로젝트 루트)
- **역할**: 등록된 퀴즈 목록과 사용자의 최고 점수 데이터를 영속적으로 저장
- **인코딩**: UTF-8

### 📄 데이터 필드 구조 (Schema)

```json
{
  "quizzes": [
    {
      "question": "LIFO(Last-In, First-Out) 특징을 가지는 자료구조는 무엇인가?",
      "choices": [
        "큐 (Queue)",
        "스택 (Stack)",
        "트리 (Tree)",
        "그래프 (Graph)"
      ],
      "answer": 1
    }
  ],
  "bestState": {
    "score": 100,
    "correct": 6,
    "total": 6
  }
}
```

- **`quizzes`** (`list`): 등록된 퀴즈 객체 배열
  - `question` (`string`): 퀴즈 문제 텍스트
  - `choices` (`list[string]`): 4개의 선택지 리스트
  - `answer` (`integer`): 정답 인덱스 (0-based)
- **`bestState`** (`dict`): 최고 점수 기록 정보
  - `score` (`integer`): 백분율 기준 최고 점수 (0~100)
  - `correct` (`integer`): 최고 점수 기록 시 맞힌 문제 수
  - `total` (`integer`): 최고 점수 기록 시 전체 문제 수
